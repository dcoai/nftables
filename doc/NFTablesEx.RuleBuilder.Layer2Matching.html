    match_vlan_id(builder, vlan_id)

    @spec match_vlan_id(NFTablesEx.RuleBuilder.t(), non_neg_integer()) ::
  NFTablesEx.RuleBuilder.t()

    Match VLAN ID.

    Used for VLAN-aware bridge filtering.

    Example

    # Match VLAN 100
builder |> match_vlan_id(100) |> accept()

# Match VLAN range (using multiple rules)
builder |> match_vlan_id(50) |> jump("vlan_50")
